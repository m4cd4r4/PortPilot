## The problem

PortPilot is used four ways: the Electron desktop app, the browser web portal, the VS Code extension, and Claude Code (plugin status line, guard, crash band, MCP tools). The README shows only desktop crops. Macdara wants screenshots or short demos of ALL ways to interact with it, current as of 3.5.0, plus a "how to talk to it" explanation per surface.
